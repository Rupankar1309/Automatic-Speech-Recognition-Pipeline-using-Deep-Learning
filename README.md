# Automatic-Speech-Recognition-Pipeline-using-Deep-Learning
Built CNN-BiGRU and CNN-BiLSTM ASR pipelines(Log-Mel Spectrogram) on LibriSpeech dataset; BiGRU outperformed BiLSTM (0.57 vs. 0.60 WER). Engineered a KenLM 4-gram decoder with Kneser-Ney smoothing and dictionary correction, reducing relative WER by 25% without retraining.
